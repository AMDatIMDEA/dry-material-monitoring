# Model weights directory

Place the trained files here using the configured names:

- `powder_best.pt`
- `polymer_best.pt`

Model files are intentionally excluded by the repository-wide `*.pt`, `*.onnx`,
and `*.engine` rules. Do not commit trained weights or replace these instructions
with a model binary. The paper weights and datasets are archived in the
[Zenodo record](https://zenodo.org/records/22697983), DOI
[`10.5281/zenodo.22697983`](https://doi.org/10.5281/zenodo.22697983). See the
[model card](../MODEL_CARD.md) for the three paper-model hashes and archived
session locations.
